# Only approved rounds reach the hub and the export

`Brand.md`, `Design.md` and the Brand Hub read approved rounds only; drafts are
absent, and unapproved deliverables are listed by name at the foot of each file
under "Not yet approved". A brand guide that mixes signed-off decisions with
machine output nobody has read is worse than no guide, because a reader cannot
tell which is which. Refreshing an approved deliverable withdraws the approval
on purpose: the approved thing is a specific round, and it is no longer what is
on screen.

## Consequences

A future reader will be tempted to "fix" the export so it includes everything,
or to keep the approval when a refresh lands. Both would remove the only signal
that says a human read this. Don't.
